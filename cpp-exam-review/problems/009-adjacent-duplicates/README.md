# 009 · 相邻重复字符整理

## 问题描述

给定一个只包含小写英文字母的字符串。请将每一段连续相同的字符整理为一个字符，其余字符的相对顺序保持不变。

例如，`aaabbccaaa` 整理后为 `abca`。

## 输入格式

输入仅包含一行字符串。字符串只由小写英文字母 `a` 到 `z` 组成，也可以为空，不包含空格或其他字符。

## 输出格式

输出一行，表示整理后的字符串。

如果输入字符串为空，输出一个空行。

## 数据范围

- 字符串长度为 0 到 10000（含端点）。
- 输入行以换行符结束，换行符不属于字符串内容。
- 每个输入文件只有一组数据。
- 每组测试运行时间限制：2 秒。

## 样例输入

```text
aaabbccaaa
```

## 样例输出

```text
abca
```

## 必要说明

样例中的 `aaa`、`bb`、`cc`、`aaa` 各自整理为一个字符。

只有相邻且相同的字符才属于同一段。同一个字符出现在不同段时，每段都要保留一次。例如，`ababa` 整理后仍为 `ababa`。
