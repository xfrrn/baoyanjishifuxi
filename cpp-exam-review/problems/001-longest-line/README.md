# 001 · 最长的一行

## 问题描述

给定按顺序编号为 1 到 n 的 n 行文本，请找出字符数最多的一行，输出它的编号和字符数。如果多行的字符数相同且均为最大值，输出其中编号最小的一行。

每个英文字母、数字和空格均计为一个字符。行首、行尾及连续出现的空格都必须计入，换行符不计入字符数。一行文本可以为空，此时字符数为 0。

## 输入格式

第一行包含一个整数 n。

接下来恰好 n 行，每行是一行文本。文本仅由大小写英文字母、数字和普通空格（ASCII 32）组成，不包含制表符。

## 输出格式

输出两个整数，中间用一个空格分隔，分别表示所选文本的编号和字符数。

## 数据范围

- 1 ≤ n ≤ 1000。
- 每行文本的字符数为 0 到 1000（含端点）。
- 所有文本的总字符数不超过 1,000,000。
- 每行均以换行符结束；换行符仅作为分隔符。
- 每组测试运行时间限制：2 秒。

## 样例输入

```text
5
Hello
CPP exam
abc  def
2026
OK
```

## 样例输出

```text
2 8
```

## 必要说明

第 2 行和第 3 行文本均有 8 个字符，因此输出编号较小的第 2 行。文本编号不包含输入中的第一行整数 n。
