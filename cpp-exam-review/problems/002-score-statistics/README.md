# 002 · 成绩达标统计

## 问题描述

某班有 n 名学生参加了一次考试，每名学生都有一个整数成绩。给定达标分数 k，成绩大于或等于 k 的学生视为达标。

请输出达标学生的人数，以及这些达标学生的成绩总和。

## 输入格式

第一行包含两个整数 n 和 k，中间用一个空格分隔。

第二行包含 n 个整数，依次表示每名学生的成绩，相邻整数之间用一个空格分隔。

## 输出格式

输出两个整数，中间用一个空格分隔，分别表示达标学生的人数和达标学生的成绩总和。

如果没有学生达标，输出 `0 0`。

## 数据范围

- 1 ≤ n ≤ 1000。
- 0 ≤ k ≤ 100。
- 每名学生的成绩均为 0 到 100 之间的整数（含端点）。
- 每个输入文件只有一组数据。
- 每组测试运行时间限制：2 秒。

## 样例输入

```text
6 60
55 60 92 48 60 85
```

## 样例输出

```text
4 297
```

## 必要说明

样例中达标学生的成绩分别为 60、92、60、85，共 4 人，成绩总和为 297。

成绩恰好等于 k 也算达标。成绩相同的不同学生分别计入人数和成绩总和。
