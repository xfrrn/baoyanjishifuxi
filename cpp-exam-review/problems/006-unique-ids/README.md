# 006 · 编号整理

## 问题描述

某次活动收集了 n 条报名记录，每条记录包含一个正整数编号。同一个编号可能在记录中出现多次。

请整理这些编号，使每个不同的编号只保留一个，并按从小到大的顺序输出。同时，输出不同编号的总个数。

## 输入格式

第一行包含一个整数 n。

第二行包含 n 个正整数，依次表示各条记录中的编号，相邻整数之间用一个空格分隔。

## 输出格式

第一行输出一个整数 m，表示不同编号的总个数。

第二行输出按从小到大顺序排列的 m 个不同编号，相邻编号之间用一个空格分隔。

## 数据范围

- 1 ≤ n ≤ 1000。
- 每个编号的取值范围为 1 到 1000000（含端点）。
- 每个输入文件只有一组数据。
- 每组测试运行时间限制：2 秒。

## 样例输入

```text
8
12 5 12 8 5 20 8 3
```

## 样例输出

```text
5
3 5 8 12 20
```

## 必要说明

样例中共有 5 个不同的编号，分别为 3、5、8、12、20。

无论一个编号在输入中出现多少次，输出时都只保留一次。如果所有编号相同，第一行应输出 `1`，第二行输出该编号。
