# 007 · 库存记录

## 问题描述

某仓库最初有 m 件货物，接下来会按给定顺序发生 n 次操作。

每次操作由两个整数 t 和 x 表示：

- 当 t 为 1 时，表示入库 x 件货物，库存增加 x。
- 当 t 为 2 时，表示申请出库 x 件货物。如果当前库存不少于 x，则出库成功，库存减少 x；否则出库失败，库存保持不变。

请输出所有操作结束后的库存，以及出库失败的次数。

## 输入格式

第一行包含两个整数 n 和 m，分别表示操作次数和初始库存，中间用一个空格分隔。

接下来 n 行，每行包含两个整数 t 和 x，中间用一个空格分隔，表示一次操作。各次操作严格按输入顺序发生。

## 输出格式

在一行中输出两个整数，中间用一个空格分隔，分别表示最终库存和出库失败的次数。

## 数据范围

- 1 ≤ n ≤ 1000。
- 0 ≤ m ≤ 1000。
- t 只能为 1 或 2。
- 1 ≤ x ≤ 1000。
- 每个输入文件只有一组数据。
- 每组测试运行时间限制：2 秒。

## 样例输入

```text
6 5
2 3
2 4
1 5
2 7
2 1
1 2
```

## 样例输出

```text
2 2
```

## 必要说明

样例中每次操作后的库存依次为 2、2、7、0、0、2。第 2 次和第 5 次操作出库失败，所以最终库存为 2，失败次数为 2。

库存恰好等于申请出库数量时，出库成功。出库失败时不会扣除任何货物，也不会在之后补做该次操作。
