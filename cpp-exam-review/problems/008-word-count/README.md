# 008 · 单词计数

## 问题描述

给定一行文本，其中只包含大小写英文字母和普通空格。

每一段连续的英文字母构成一个单词。单词之间由一个或多个空格分隔，文本的开头和结尾也可能有空格。

请输出这行文本中的单词总数。

## 输入格式

输入仅包含一行文本，文本长度可以为 0。文本只由大小写英文字母和普通空格（ASCII 32）组成，不包含数字、标点或制表符。

## 输出格式

输出一个整数，表示文本中的单词总数。

如果文本为空或只包含空格，输出 `0`。

## 数据范围

- 文本长度为 0 到 10000（含端点），空格计入长度。
- 输入行以换行符结束，换行符不属于文本内容。
- 每个输入文件只有一组数据。
- 每组测试运行时间限制：2 秒。

## 样例输入

```text
Hello   CPP exam
```

## 样例输出

```text
3
```

## 必要说明

样例包含 `Hello`、`CPP`、`exam` 三个单词。连续出现的多个空格不会产生额外的单词。

每次出现的单词都要计数。例如，`go go` 有 2 个单词；`aBc` 是 1 个单词，字母大小写变化不会分隔单词。
