# 012 · 跨文档热门词

## 问题描述

某资料库收录了 n 篇文档，每篇文档用一行文本表示。现在需要统计资料库中的热门词，并输出排名最靠前的 k 个不同单词。

单词及统计规则如下：

1. 一个单词是一段连续的英文字母，且这段字母不能向左右继续扩展。除英文字母外的所有字符均作为分隔符。例如，`C++17data_base` 中有三个单词：`C`、`data`、`base`。
2. 单词不区分大小写，输出时统一使用小写字母。
3. 每个单词有两个统计量：**文档数**表示包含该单词的文档篇数；**总次数**表示该单词在所有文档中出现的总次数。同一单词在一篇文档中出现多次时，文档数只增加 1，总次数按实际出现次数增加。
4. 不同单词按以下优先级排名：文档数较多的在前；文档数相同时，总次数较多的在前；两项都相同时，小写单词字典序较小的在前。

如果不同单词不足 k 个，则输出全部单词；如果所有文档都不含单词，则输出数量 0。

## 输入格式

第一行包含两个整数 n 和 k，用一个空格分隔。

接下来 n 行，每行表示一篇文档。文档可能为空行，也可能有行首、行尾或连续的空格、制表符。空行仍然算一篇文档。

## 输出格式

第一行输出一个整数 r，表示实际输出的不同单词数量。

接下来 r 行，按题目规定的排名顺序，每行输出：

```text
单词 文档数 总次数
```

三个字段之间用一个空格分隔。如果 r 为 0，则不再输出其他行。

## 数据范围

- 1 ≤ n ≤ 1000。
- 1 ≤ k ≤ 1000。
- 每篇文档长度为 0 到 1000 个字符，不计行末换行符。
- 所有文档的字符数之和不超过 200000。
- 文档只包含可打印 ASCII 字符（包括空格、字母、数字和标点等）及水平制表符；英文字母仅指 `A`～`Z` 和 `a`～`z`。
- 每个输入文件只有一组数据。
- 每组测试运行时间限制：2 秒。

## 样例输入

```text
4 5
Data, data! Structures and C++.
c++ and algorithms; DATA.
Algorithms: data structures.
C++17; C AND data.
```

## 样例输出

```text
5
data 4 5
c 3 4
and 3 3
algorithms 2 2
structures 2 2
```

## 必要说明

`data` 出现在全部 4 篇文档中，在第一篇出现 2 次，其余三篇各出现 1 次，因此文档数为 4，总次数为 5。

`c` 和 `and` 的文档数都为 3，但总次数分别为 4 和 3，因此 `c` 排在前面。`algorithms` 和 `structures` 的两项统计均相同，按字典序排列。

数字和标点只起分隔作用，例如 `abc123def` 包含 `abc` 和 `def` 两个单词。内容完全相同的两行仍分别算作两篇文档。

字典序按小写字母从左到右比较；如果一个单词是另一个单词的前缀，较短的在前。例如 `a`、`aa`、`app`、`apple` 按此顺序排列。
