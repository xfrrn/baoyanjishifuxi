# 005 · 身高排序

## 问题描述

某班有 n 名学生，已知每名学生的身高，单位为厘米。

请将这些身高按从小到大的顺序输出。如果多名学生的身高相同，每个人的身高都必须保留。

## 输入格式

第一行包含一个整数 n。

第二行包含 n 个整数，依次表示每名学生的身高，相邻整数之间用一个空格分隔。

## 输出格式

在一行中输出按从小到大顺序排列的 n 个身高，相邻整数之间用一个空格分隔。

## 数据范围

- 1 ≤ n ≤ 1000。
- 每名学生的身高均为 100 到 220 之间的整数（含端点）。
- 每个输入文件只有一组数据。
- 每组测试运行时间限制：2 秒。

## 样例输入

```text
6
170 160 175 160 180 165
```

## 样例输出

```text
160 160 165 170 175 180
```

## 必要说明

样例中有两名学生的身高为 160 厘米，因此输出中应保留两个 `160`。

输出的是身高数值，不是学生原来的编号。
