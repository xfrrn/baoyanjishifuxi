# 003 · 倒序输出

## 问题描述

给定按顺序排列的 n 个整数，请按照与输入相反的顺序输出这些整数。

所有整数都必须保留，重复出现的整数也要分别输出。

## 输入格式

第一行包含一个整数 n。

第二行包含 n 个整数，相邻整数之间用一个空格分隔。

## 输出格式

在一行中输出倒序后的 n 个整数，相邻整数之间用一个空格分隔。

## 数据范围

- 1 ≤ n ≤ 1000。
- 每个整数的取值范围为 -1000 到 1000（含端点）。
- 每个输入文件只有一组数据。
- 每组测试运行时间限制：2 秒。

## 样例输入

```text
5
8 0 -3 8 12
```

## 样例输出

```text
12 8 -3 0 8
```

## 必要说明

倒序是将原来的最后一个数放在最前面，倒数第二个数放在第二个位置，依此类推。

整数本身的数值不改变。例如，`12` 倒序后仍为 `12`，不会变成 `21`。
