# 011 · 最常出现的编号

## 问题描述

给定 n 条记录，每条记录包含一个正整数编号。同一个编号可能出现多次。

请找出出现次数最多的编号。如果有多个编号的出现次数相同且均为最多，选择其中数值最小的编号。

输出所选编号及其出现次数。

## 输入格式

第一行包含一个整数 n。

第二行包含 n 个正整数，依次表示各条记录中的编号，相邻整数之间用一个空格分隔。

## 输出格式

在一行中输出两个整数，中间用一个空格分隔，分别表示所选编号和它的出现次数。

## 数据范围

- 1 ≤ n ≤ 1000。
- 每个编号的取值范围为 1 到 1000（含端点）。
- 每个输入文件只有一组数据。
- 每组测试运行时间限制：2 秒。

## 样例输入

```text
9
7 2 7 5 2 7 5 5 9
```

## 样例输出

```text
5 3
```

## 必要说明

样例中，编号 5 和编号 7 都出现了 3 次，是出现次数最多的编号。因为 5 小于 7，所以输出 `5 3`。

统计的是编号在全部记录中的出现次数，不要求这些记录相邻。并列时比较编号的数值，不比较它们首次出现的位置。
