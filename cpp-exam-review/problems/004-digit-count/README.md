# 004 · 逐行数字统计

## 问题描述

给定 n 行文本，请分别统计每一行中数字字符的个数。

数字字符指 `0` 到 `9`。其他字符不计入答案。

## 输入格式

第一行包含一个整数 n。

接下来恰好 n 行，每行是一行文本。文本仅由大小写英文字母、数字和普通空格（ASCII 32）组成，不包含制表符。

一行文本可以为空，也可以包含行首、行尾或连续出现的空格。

## 输出格式

输出 n 行。第 i 行输出一个整数，表示第 i 行文本中的数字字符个数。

如果某行文本为空或不含数字字符，对应输出 `0`。不要输出额外的行号或说明文字。

## 数据范围

- 1 ≤ n ≤ 100。
- 每行文本的长度为 0 到 1000（含端点）。
- 所有文本的总长度不超过 100000。
- 每行均以换行符结束，换行符仅作为分隔符。
- 每个输入文件只有一组数据。
- 每组测试运行时间限制：2 秒。

## 样例输入

```text
4
Room 207
CPP 17
123 45
No digits
```

## 样例输出

```text
3
2
5
0
```

## 必要说明

`Room 207` 中有 `2`、`0`、`7` 三个数字字符。

统计的是数字字符的个数。例如，`123` 的答案是 `3`，`000` 的答案也是 `3`。

文本行编号不包含输入中的第一行整数 n。
