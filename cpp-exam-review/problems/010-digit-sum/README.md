# 010 · 数位和

## 问题描述

一个非负整数的数位和，是它的十进制表示中各位数字的总和。例如，305 的数位和为 3 + 0 + 5 = 8。

给定 n 个非负整数，请分别输出每个整数的数位和。

## 输入格式

第一行包含一个整数 n。

第二行包含 n 个非负整数，相邻整数之间用一个空格分隔。除整数 0 本身外，输入的整数不含前导零。

## 输出格式

输出 n 行。第 i 行输出一个整数，表示输入中第 i 个非负整数的数位和。

## 数据范围

- 1 ≤ n ≤ 1000。
- 每个待处理整数的取值范围为 0 到 1000000000（含端点）。
- 每个输入文件只有一组数据。
- 每组测试运行时间限制：2 秒。

## 样例输入

```text
4
305 0 999 1002
```

## 样例输出

```text
8
0
27
3
```

## 必要说明

整数 0 的数位和为 0。

分别计算每个整数的答案，不要将多个整数的数位和合并。例如，999 的答案是 27，不需要继续将 2 和 7 相加。
