## 开始练习

测评实际执行流程：`main.cpp → g++ 编译 → Windows 原生 .exe → 输入测试数据 → 比较输出`。Python 仅负责启动编译器、运行程序和判定结果，不解释或模拟 C++ 代码。每次测评会显示编译器路径和实际运行的程序路径。

打开 [当前题目](problems/012-document-keywords/README.md)，只编辑该题的 `main.cpp`。

在本目录执行（Python 3.9+、支持 C++17 的 g++）：

```sh
python tools/judge.py
```

也可指定题目或模拟题目录：

```sh
python tools/judge.py problems/001-longest-line
python tools/judge.py mocks/mock-01/03-programming
```

脚本以 `progress.md` 的“当前题目”为默认目标，与启动目录无关。默认每组限时 2 秒，编译限时 30 秒；可用 `--timeout 3` 调整运行限时。编译命令为 `g++ main.cpp -std=c++17 -O2 -Wall -o <临时程序>`。优先读取环境变量 `CXX`（单个编译器路径），其次查找 PATH，最后读取本机的 `tools/compiler-path.txt`（若存在）。移动到其他电脑后可设置 `CXX` 或将 g++ 加入 PATH。

本机已在 `tools/toolchain/` 配置 Windows 便携编译器，无需修改系统 PATH。来源：[w64devkit 2.9.1 官方发行页](https://github.com/skeeto/w64devkit/releases/tag/v2.9.1)，下载包 `w64devkit-x64-2.9.1.7z.exe` 的 SHA256 已核对为 `9208c19755cd4964b7915b9afcf02c66d493a4c870c4b3e83f6c538d9c1237a5`。Linux 上使用 PATH 中的 g++。脚本使用跨平台 Python 标准库，当前已在 Windows 实机验证；未在 Linux 实机运行。

输出按行比较：忽略 CRLF/LF 差异、各行末尾空格/制表符、末尾空行；保留行内空格、行首空格和行结构。所有 `tests/*.in` 必须有对应 `.out`，且至少 8 组；样例也包含在 tests 中。失败用例展示完整输入、预期输出和实际输出，大用例可能较长。

测评不会改写 `main.cpp`；临时程序在结束后清理。脚本更新进度表中的状态，教练根据实际提交补充复盘和已确认的错误类别。用时仅记录你提供的实际练习时间，不把离开电脑的时间计入。初始化的参考验证不计入你的成绩。

## 交互命令

| 命令 | 行为 |
|---|---|
| 下一题 | 读取进度，只创建一道题；通过后不自动出题 |
| 测评 | 编译并运行当前题全部测试，不修改你的代码 |
| 提示 / 再提示 | 依次提供方向、核心思想、关键步骤；完整代码仅在明确说“给我完整答案”后提供 |
| 讲解 | 未通过时按当前提示级别说明；通过后简述考点、推荐思路、时间/空间复杂度和实际代码的 1～3 个注意点 |
| 重做 | 保留原提交备份后恢复空模板，重新练习当前题 |
| 开始模拟 | 新建 mock-XX：单选、填空、两道编程题；期间不提示、不分析、不公布答案 |
| 结束模拟 | 结束后判题和复盘；模拟期间仅在明确提交某题时判该题 |
| 查看进度 / 查看错题 | 展示 progress.md / mistakes.md |

## 训练路线

1. Stage 1：输入输出、getline、string、vector、循环、条件、函数、数组、排序与下标。
2. Stage 2：STL、分词、统计、排序去重、集合操作及并列规则。
3. Stage 3：模拟、枚举、前缀和、双指针、二分、栈/队列、基础 BFS/DFS 和简单贪心。
4. Stage 4：按一单选、一填空、两编程组织模拟，参考往年难度。

后续以往年机试难度为基准，在字符串与数据处理、模拟和基础算法组合题之间轮换；将实际错误对应的强化融入综合题，不再按初期简单题比例出题。不主动安排复杂竞赛算法。

错误按类别累计，不重复建项；同类错误连续出现至少两次，后续 2～3 题内安排一道不同题面强化。题目数据只采用题面允许的输入，且至少覆盖样例、最小、普通、边界、重复、极端位置、易错特殊情况和大规模数据。

目录：`problems/` 保存独立练习，`mocks/` 保存模拟，`tools/` 保存本地测评。`python tools/test_judge.py` 可运行测评器自检。

初始化校验（2026-09-09）：001 共 14 组合法测试，标准答案经独立检查和临时 C++ 参考实现验证全部通过；临时参考源码及程序已删除。测评器的 AC、WA、RE、TLE、CE、源文件不变与测试配对检查均已通过。
